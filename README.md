## 🚀 Overview

**AuthBoot Starter Kit** provides ready-to-use application templates for developers building applications with AuthBoot.

Whether you're building an Android app, an iOS app, a cross-platform application, or a WeChat Mini Program, these starter kits help you get started quickly without repeatedly building foundational infrastructure.

Spend less time on setup and more time bringing your ideas to life.

## 📦 Starter Kits

| Platform | Description | Directory |
|---|---|---|
| Android | Native Android application starter kit | [`android`](./android) |
| Flutter | Cross-platform application starter kit | [`flutter`](./flutter) |
| iOS | Native iOS application starter kit | [`ios`](./ios) |
| WeChat Mini Program | WeChat Mini Program starter kit | [`wechat-mini`](./wechat-mini) |

## ✨ Features

- **Multi-platform** — Starter kits for Android, iOS, Flutter, and WeChat Mini Programs.
- **AuthBoot Integration** — Build applications with AuthBoot authentication and user infrastructure.
- **Ready to Build** — Start with a foundation instead of reinventing the wheel.
- **Developer Friendly** — Simplified setup and development workflows.
- **Extensible** — Customize the starter kits to fit your application's needs.

## 🎯 Why AuthBoot Starter Kit?

Every new application shouldn't require rebuilding the same infrastructure.

Authentication, user management, and foundational integrations are essential, but they shouldn't slow down your product development.

AuthBoot provides the infrastructure. Starter Kits provide the starting point.

**Less Setup. More Building.**
